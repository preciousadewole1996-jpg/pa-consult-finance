# P&A Consult — Financial Service Website

A multi-page financial advisory and household budgeting website built with HTML, CSS, and JavaScript.

## Overview
- **Landing Page (`index.html`):** Features the hero section, four financial service cards (Household Budgeting, Financial Inclusion, Economic Stability, Personal Advisory), four advisory plans, and contact footer.
- **Consultation Sign-Up (`signup.html`):** Includes a consultation request form with URL plan pre-selection and an interactive confirmation state.
- **Styles & Scripts (`assets/css/style.css`, `assets/js/main.js`):** Handles responsive grid layouts, plan selection from query parameters, and form submission feedback.
- **Images (`assets/images/`):** Contains `hero-finance.jpg`, `service-budgeting.jpg`, `service-inclusion.jpg`, `service-stability.jpg`, and `service-advisory.jpg`.

## Local Preview
Open `index.html` in a web browser or launch it through a local server (such as the VS Code Live Server extension).
